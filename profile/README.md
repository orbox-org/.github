## About

Orbox builds production-grade platforms for property and operations teams. We combine spec-driven backends with AI-native agent workflows so complex work stays reliable, observable, and secure.

We are based in the **United Arab Emirates** and ship with a bias toward clear architecture, strong tenancy boundaries, and async-by-default services.

## What we work on

| Area | Focus |
|------|--------|
| **Platform** | Multi-tenant services, APIs, and data layers built for real-world operations |
| **Agents** | Production AI agent backends for workflows that need guardrails and integration |
| **Product** | Web experiences and internal tools that connect teams to the platform |
