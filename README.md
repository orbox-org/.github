# orbox-org/.github

Organization-wide defaults and the **public** GitHub organization profile.

## Organization profile README

The README shown on [github.com/orbox-org](https://github.com/orbox-org) (Overview → **Public** view) lives at:

**[`profile/README.md`](profile/README.md)**

Edit that file to update the public org homepage. Images should use absolute URLs (for example `https://raw.githubusercontent.com/orbox-org/.github/main/profile/assets/...`) so they render on the org profile.

## Member-only profile

Internal onboarding and repository details for org members are in the private **[`.github-private`](https://github.com/orbox-org/.github-private)** repository at `profile/README.md` (Overview → **Member** view).
